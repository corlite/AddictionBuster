# Code of Conduct

AddictionBuster aims to be a practical, respectful open-source project.

## Expected Behavior

- Be kind and constructive.
- Assume good intent, but accept correction.
- Keep issues and pull requests focused on the project.
- Respect that device-compatibility problems can be frustrating.
- Avoid sharing private user data, sensitive logs, or personal information.

## Unacceptable Behavior

- Harassment, insults, or personal attacks.
- Spam or intentionally misleading reports.
- Publicly posting sensitive security details before maintainers can respond.
- Sharing diagnostic logs that expose someone else's private data.

## Enforcement

Maintainers may edit, hide, or remove comments and may block users who repeatedly violate these expectations.
