# 角色图标与语音使用说明

本文说明“角色与语音”坑位如何准备素材、导入素材，以及当前版本会在哪些场景使用这些素材。

## 素材数量

每个角色槽位需要：

- 图标：1 个。
- 语音：9 条，不能复用。

当前预留槽位：

- 咕嘎
- Doro
- 自定义

如果三个槽位都要完整配置，总共需要：

- 图标：3 个。
- 语音：27 条。

如果只配置一个槽位，则只需要：

- 图标：1 个。
- 语音：9 条。

## 图标要求

图标可以复用。例如你可以让咕嘎、Doro、自定义临时使用同一张占位图。

建议规格：

- 格式：PNG、JPG 或 WebP。
- 尺寸：512x512 或 1024x1024。
- 构图：主体居中，边缘留出安全边距。
- 背景：透明 PNG 最合适；不透明背景也可以。

当前 App 内会在这些地方显示角色图标：

- 主页“今日状态”区域。
- Challenge overlay 顶部。
- 今日报告空状态。
- 设置页“角色与语音”状态区。

## 语音要求

语音不能复用。每个角色槽位需要 9 条独立语音：

| 场景 | 用途 | 建议长度 |
| --- | --- | --- |
| 拦截出现 | 打开受控 App、App 时长到等普通拦截出现时播放 | 1-3 秒 |
| 挑战通过 | 完成挑战并获得放行时播放 | 1-3 秒 |
| 手机时长到 | 手机每日/本次总时长达到限制时播放 | 1-3 秒 |
| 权限异常 | 无障碍、悬浮窗或前台服务异常时播放 | 1-4 秒 |
| 管控应用 | 主页管控应用区域出现时播放 | 1-3 秒 |
| 已管控应用 | 进入已管控应用列表时播放 | 1-3 秒 |
| 添加应用 | 进入添加管控应用页面时播放 | 1-3 秒 |
| 今日报告 | 进入今日报告页面时播放 | 1-3 秒 |
| 拦截规则 | 进入单 App 拦截规则页时播放 | 1-3 秒 |

建议格式：

- OGG 优先。
- MP3、WAV 也可以。
- 单条语音尽量小于 300 KB。
- 音量先做归一化，避免某一条特别响。

建议命名：

```text
guga_icon.png
guga_block_appeared.ogg
guga_challenge_passed.ogg
guga_phone_limit_reached.ogg
guga_permission_issue.ogg
guga_control_apps.ogg
guga_active_apps.ogg
guga_add_apps.ogg
guga_today_report.ogg
guga_app_rule.ogg

doro_icon.png
doro_block_appeared.ogg
doro_challenge_passed.ogg
doro_phone_limit_reached.ogg
doro_permission_issue.ogg
doro_control_apps.ogg
doro_active_apps.ogg
doro_add_apps.ogg
doro_today_report.ogg
doro_app_rule.ogg
```

## 导入步骤

1. 打开“瘾头破坏器”。
2. 进入“设置”。
3. 进入“角色与语音”。
4. 选择槽位：咕嘎、Doro 或自定义。
5. 点击“导入当前角色图标”，选择图片文件。
6. 分别导入 9 条语音：
   - 拦截出现
   - 挑战通过
   - 手机时长到
   - 权限异常
   - 管控应用
   - 已管控应用
   - 添加应用
   - 今日报告
   - 拦截规则
7. 开启“角色语音”。
8. 调整音量。
9. 点击各场景的试听按钮确认语音可播放。

## 当前限制

- APK 不内置咕嘎或 Doro 的图片、语音素材。
- App 只保存系统文件选择器返回的 URI，不会把素材复制进 APK。
- 如果移动或删除原始文件，部分系统上可能导致 URI 失效，需要重新导入。
- 桌面启动图标暂不支持切换；当前只是 App 内角色图标。
